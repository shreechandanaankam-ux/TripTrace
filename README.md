# ✈️ TRIPTRACE 

### Plan Smarter. Travel Better. Explore Together!

TripTrace is a web-based travel planning application designed to make trip planning simple, interactive, and engaging. It connects experienced travelers (Mentors) with new travelers through reusable trip templates, personalized itineraries, interactive maps, budget calculations, and collaborative features.

The platform allows mentors to share their travel experiences through detailed trip templates, while travelers can explore, customize, and plan their own journeys.

---

## 📌 Project Overview

Planning a trip often involves searching across multiple platforms for destinations, transportation, activities, schedules, and budget information.

TripTrace addresses these challenges through a mentor-driven collaborative platform where experienced travelers can create structured trip plans and share them with others.

The application features a unique comic-style interface that makes travel planning more enjoyable and user-friendly.

## 🎯 Objectives

- Simplify the travel planning process.
- Connect experienced travelers with new travelers.
- Provide reusable, mentor-created trip templates.
- Generate structured day-wise itineraries.
- Calculate individual and group travel budgets.
- Visualize destinations through interactive maps.
- Encourage collaboration and sharing of travel experiences.

---

## ✨ Key Features

### 👨‍🏫 1. Mentor Module

Mentors can create and manage reusable travel templates.

- Create multi-day trip templates.
- Add Morning, Afternoon, Evening, and Night activities.
- Include transportation details.
- Add budget estimates for each activity.
- Upload images, videos, and other media.
- Add destination locations using map markers.
- Edit, view, and delete created templates.
- Monitor traveler feedback.

### 🧳 2. Traveler Module

Travelers can explore and customize mentor-created travel plans.

- Explore available trip templates.
- View destination information and travel media.
- Discover locations through an interactive map.
- Select a trip template.
- Customize activities and schedules.
- Choose the number of travel days and participants.
- Generate personalized itineraries.
- Save planned trips.

### 🗺️ 3. Interactive Map Integration

- Uses Leaflet.js for map visualization.
- Displays mentor-pinned destinations.
- Allows travelers to explore locations interactively.
- Loads location markers dynamically from trip templates.

### 💰 4. Automatic Budget Calculation

- Calculates activity-wise budgets.
- Includes transportation expenses.
- Supports group travel calculations.
- Displays the estimated grand total for the trip.

### ❓ 5. Q&A Module

- Travelers can ask questions about trips, destinations, and activities.
- Mentors and experienced travelers can provide answers.
- Encourages collaborative travel knowledge sharing.

### ⭐ 6. Feedback and Media Module

- Travelers can submit feedback.
- Supports ratings and comments.
- Allows photo and video uploads.
- Helps mentors improve their travel templates.

### 🔐 7. Login and Registration

- Provides user registration and login.
- Supports Mentor and Traveler roles.
- Validates user input.
- Stores user information and roles using browser localStorage.

## ⚙️ System Architecture

TripTrace consists of two main user perspectives:

**1. Mentor Side**

Mentor → Create Trip Template → Add Activities → Add Transport and Budget → Upload Media → Add Map Locations → Save Template

**2. Traveler Side**

Traveler → Explore Templates → Select Trip → Customize Activities → Generate Itinerary → Calculate Budget → Save Trip

### Application Workflow

1. Users register and select their role.
2. Mentors create and save multi-day travel templates.
3. Templates are stored in browser localStorage.
4. Travelers explore available templates.
5. Travelers select and customize a trip.
6. The planner generates day-wise activity sections.
7. The application calculates the estimated travel budget.
8. Travelers save their personalized trip.
